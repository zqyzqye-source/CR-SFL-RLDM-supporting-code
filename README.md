# Supporting Code for CR-SFL-RLDM

This repository contains a partial release of experimental
scripts and supporting modules related to the paper
"Robust Spline Functional Link Adaptive Filter for
Nonlinear Censored Regression".

## Contents

- Section A: an experimental script associated with Fig. 2(a).
- Section B: data-recovery and MSE visualization utilities.
- Section C: speech-preprocessing, waveform-generation,
  and plotting utilities.
